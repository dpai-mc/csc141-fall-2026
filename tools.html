AI Tools in This Course

Every AI tool the course names, which module it comes up in, and what it was built to be.

This is a map, not a ranking. Most of the tools below are general-purpose assistants, and the differences you notice between them come mostly from the product built around the model rather than from a fixed list of powers. Module 3 is where the course takes that distinction apart. Read “what it’s built to be” as a starting premise, not a scorecard.

Gemini is your baseline — the one tool everyone in the class has, so demonstrations and screenshots use it. Past that, the choice is yours unless an activity names a tool and says why. You will never need an account outside the college to finish this course.

Where each tool comes up

Select a module to open it. A tool is listed in the module that introduces it; once introduced, it stays available to you for the rest of the semester.

Module 1 How AI Actually Works Weeks 1–3

Module 1 introduces the whole landscape at once, so you know what exists before the course starts asking you to compare things.

Gemini College-provided gemini.google.com

Google’s general-purpose assistant. It is the course baseline because every student already has it through the college Google Workspace account — which is the only reason a step-by-step instruction can mean the same thing to everybody.

Microsoft Copilot College-provided copilot.microsoft.com

Microsoft’s general-purpose assistant, reached with the same college sign-in. Web only on the student tier. This is the course’s fallback if you cannot get into Gemini — every activity here can be done in it.

NotebookLM College-provided notebooklm.google.com

Built to answer only from sources you upload, rather than from whatever it absorbed in training. That single design choice makes it behave quite differently from a general chatbot. Requires you to be 18 or older, even on the college account.

Named in Module 1; the course returns to it when we reach source-grounded research.

ChatGPT Personal account chatgpt.com

OpenAI’s general-purpose assistant — the product that put this whole category in front of the public in late 2022.

Claude Personal account claude.ai

Anthropic’s general-purpose assistant. Appears in the course as a named alternate where comparing two tools teaches something. Requires you to be 18 or older.

Perplexity Personal account perplexity.ai

Built retrieval-first: it searches by default and puts its sources in front of you. That is a difference in default posture, not a difference in kind — the other assistants search too.

Introduced in Module 1; worked through properly in Module 3.

Grok Personal account grok.com

A general-purpose assistant from SpaceXAI, built with direct access to live posts on X.

DeepSeek Personal account deepseek.com

A general-purpose assistant notable for publishing the weights of several of its models openly — unusual among the hosted services on this list. It is developed and operated outside the United States, so the rules its data sits under are different ones; the course’s data page covers what that means.

Module 2 Generative AI & the Art of the Prompt Weeks 4–6
Open-weight / local models Your own hardware

Not one product but a category: models whose weights are published, so they can be downloaded and run on hardware you control instead of being reached through somebody else’s service. Llama (llama.com) and Mistral (mistral.ai) are two you will run into.

Module 2 is where you compare this category against the frontier models on capability, privacy, cost and control — you will build that comparison yourself, so it is deliberately not filled in here.

Module 3 AI as a Learning Partner — Honestly Weeks 7–8

No new tools to sign up for. Module 3 is where the tools you already have get taken apart — what a model is, what the product around it adds, and how an answer actually got assembled.

Perplexity Personal account perplexity.ai

Returns here as the worked example of a retrieval-first product, contrasted with how the same question travels through a general assistant.

Comet Personal account perplexity.ai/comet

Perplexity’s web browser with an assistant built in that can act on a page rather than only answer questions about it. Mentioned here in passing; tools that take actions on your behalf are a Module 6 topic.

Module 4 When AI Gets It Wrong: Bias, Privacy & Security Weeks 9–11
Latimer Case study latimer.ai

Built on a deliberately curated training corpus — including licensed archives such as the New York Amsterdam News, which has been published since long before the web — on the premise that what a model was trained on determines whose history it is able to represent. Module 4 uses it to make one idea concrete: the record existed, but its digitizing and indexing did not happen evenly, and a model trained by scraping the open web inherits that unevenness.

Read about and discussed in Module 4. You are not asked to create an account.

Module 5 AI in Your World: Work & Your Field Weeks 12–14

No new tools. By Module 5 you have met everything the course is going to hand you. This module is about putting what you already have into a real workflow in your own field — which is a different skill from collecting more tools.

Module 6 Governing AI & Owning Your Future Weeks 15–17

No new sign-ups. Module 6 looks forward at categories of tool rather than at particular products — including systems that take actions on your behalf, which is where Comet and tools like it are properly discussed.
