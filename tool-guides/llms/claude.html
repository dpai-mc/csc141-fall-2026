1. What This Tool Is

What Claude is — and where it sits in this course.

Claude is Anthropic’s conversational AI assistant. You talk to it in plain language: you type a question or a task, it answers, and you can keep the conversation going. In this course you’d use it the way you’d use any conversational assistant — to ask questions about material, draft and revise writing, and summarize documents.

Note

Claude is one of the two named alternates in this course’s demonstrations; the other is Microsoft Copilot. Nothing in this course requires Claude — a student who never opens this guide must still be able to pass every assessment. This guide teaches the Claude interface only: what an LLM is, how to write prompts, and how to evaluate output belong to the lessons listed in Section 8.

2. Getting Access

A personal account under Anthropic’s own terms — and what that means before you sign up.

This tool is not provided or supported by Mendocino College. Using it means creating a personal account under Anthropic’s own terms of service, with your own email — not your student email. Nothing in this course requires you to use it; every activity can be completed with a college-supported tool.

Before you sign up, know what you’re agreeing to: Anthropic does not use your conversations to train its models unless you choose to let it. Consumer accounts are asked to make that choice in an in-app notification, and the setting lives in Privacy Settings; if you decline, chats fall under a 30-day retention period, and if you agree, retention for new or resumed chats extends to five years (Anthropic, Updates to Consumer Terms and Privacy Policy, changes effective from 2025-08-28 with an existing-user deadline of 2025-10-08; verified 2026-08-19). Never enter your student ID, grades, other students’ work, anyone’s personal information, or anything you’d be uncomfortable seeing outside this course.

Caution

You must be 18 to use Claude. Anthropic’s own wording: “We require all users to be at least 18 years old to create and use a Claude account.” On phones and tablets, app-store age information is used to enforce this, and an account identified as under 18 is blocked from signing in on the mobile app. Anthropic can’t change that information itself — a student who believes it’s wrong has to fix it with Apple or Google support. (Anthropic Help Center, Minimum age requirement access restriction, published 2026-03-16; verified 2026-08-19.)

If you’re under 18, use Gemini or Copilot. Both are college-provided, both cover every activity in CSC 141, and you lose nothing by skipping this tool.

Step by step: signing up for Claude

  1. Go to Claude on the web. Open Claude’s website in a browser tab and choose to sign up.

  2. Sign up with your own email, or with Google sign-in. Use a personal address, not your @student.mendocino.edu one — a student address would create a personal Anthropic account that merely looks institutional, and would put coursework under a vendor relationship the college has no agreement with.

  3. Expect the screen to ask what it asks.

    Whether a phone number is required at signup is not stated in this guide; it was not verified for this build. Trust whatever the signup screen actually asks.

  4. Test it. Type Say hello and press Enter. If you get a response, you’re set.

What a free account gets you — and how its usage limit works — is covered in Section 5.

3. The Interface

The screen you actually land on, at the depth this course needs.

This is a short tour of the screen a student actually lands on — enough to work the course activities, not an exhaustive feature tour. You’ll still see buttons for Projects, Artifacts and other features; naming them is fine, walking through them is out of scope here.

Interface tour — six things worth finding

The prompt input box

The single text field where you type what you want. Everything you do with Claude starts here.

The conversation thread

Your prompts and Claude’s responses in sequence. Everything above the current message is context the conversation still carries.

Starting a new chat vs. continuing one

Starting a new chat opens an empty thread with no memory of the previous one; continuing in the current thread keeps its context. When to do which is Activity 3 in Section 4.

Chat history

Previous conversations, listed and reachable again later.

The model selector

A control for choosing which model handles your conversation.

Attaching a file or image

An attach control near the input box lets you add a document or image and then ask questions about it.

4. Core Workflow

Three short activities that exercise the interface. The same three appear in every tool guide, in the same order.

These prompts exist to make the buttons do something so you can see what happens. Writing good prompts is a separate skill, taught in Module 2, Lessons 3 and 4 (M2L3–M2L4).

Activity 1 — Ask and follow up

5 min

Task: ask one question, then ask a second question that only makes sense if the first one is remembered.

  1. Open a new chat and paste the first prompt.
  2. Read the response.
  3. In the same thread, paste the follow-up. Don’t repeat the topic — the point is to see whether the thread carries it.

First prompt:

Explain what a community college transfer agreement is, in about four sentences.

Follow-up, in the same thread:

Now say that again for someone who has never heard the word "articulation."

Activity 2 — Attach something

5 min

Task: upload a document or image and ask a question about it.

  1. Find a file you already have — a syllabus, a handout, a photo of a printed page. Nothing personal: no student ID, no grades, nobody else’s work.
  2. Use the attach control near the input box to add it.
  3. Paste the prompt below and send it.

Prompt:

Summarize this document in five bullet points, then list anything in it you are unsure about.

Activity 3 — Start clean

2 min

Task: notice the difference between continuing a thread and starting a new one.

  1. Still in the thread from Activity 2, paste the prompt below. The answer will probably still be coloured by the document you attached.
  2. Now start a new chat and paste the same prompt into the empty thread.
  3. Compare. A long thread carries everything in it — useful when that’s what you want, and a source of drift when it isn’t. When you change topic, start clean.

Prompt (run it twice — old thread, then new chat):

What are three good ways to take notes during a lecture?

On the free plan there’s a second, concrete reason to start clean: a long thread consumes your usage allowance faster — see Section 5.

5. Free-Tier Limits

What the free tier gets you — and where Anthropic stops being specific.

This section is accurate as of August 2026, verified against Anthropic’s published pricing page on 2026-08-19. It is the fastest-staling section in the guide — re-verify it every term, and check it against your own screen before relying on it.

Usage is metered by a rolling window, not a message count. Anthropic: “Every plan has usage limits that reset on a rolling five-hour session window.” Free “covers everyday questions”; Pro is described as at least 5× more usage per 5-hour session than Free.

Anthropic does not publish a message number for Free. How fast you consume the allowance depends on conversation length and complexity, which model you’re using, the features you use, and the effort level selected (Anthropic Help Center, How do usage and length limits work?). Third-party “Claude free limits 2026” pages state confident numbers that Anthropic doesn’t publish and that contradict each other — where a figure isn’t published, this guide says so.

Available on Free per the pricing page: chat on web, iOS, Android and desktop; web search; memory across conversations; file creation; code execution; extended thinking.

All of the above: Anthropic’s pricing page, verified 2026-08-19.

Verify

This is a different shape of limit than a message counter, and it’s worth noticing: you can’t plan around “20 messages a day” because that isn’t the unit. A long, complex conversation costs more of your window than several short ones. If you hit the limit mid-assignment, the wait is until the window rolls over — which is a good argument for not starting graded work on a free tier an hour before it’s due.

6. Privacy & Data Handling

What Anthropic does with what you type, and how to check it yourself.

Data posture at a glance

Account
Personal account under Anthropic’s own terms. No college agreement applies to it.
Training on your inputs
No, unless you opt in. You’re asked once; the setting lives in Privacy Settings. Anthropic, verified 2026-08-19
Who else can see it
Anthropic, per its own policy. There is no institution in between and nobody at the college to ask.
Retention
30 days if you decline training; five years for new or resumed chats if you opt in.

The detail

  • Training is opt-in, not on by default. Consumer users get an in-app notification asking whether to share chats and coding sessions for model improvement; the preference lives in Privacy Settings and can be changed at any time.
  • Retention depends on that choice: decline and chats fall under the existing 30-day retention period; agree and retention for new or resumed chats extends to five years. Conversations with no further activity from before the change aren’t used for training.
  • The dates matter here: the change rolled out from 2025-08-28, with existing users required to choose by 2025-10-08 to keep using Claude.
  • Where the controls are. The training preference lives in Privacy Settings, and you can change it at any time. The current menu path was not verified for this build — if you can’t find it where this guide says, look for a setting about privacy or training.
Verify

The in-product check. Open Privacy Settings on your own account and read what your training preference is actually set to. You answered this question once, possibly quickly, when you signed up. Go and see what you said.

Caution

The standing rule, whatever tool you’re using: never enter your student ID, grades, other students’ work, or anyone’s personal information.

7. Known Weaknesses

The failure modes you will actually hit in this course.

  • Confident wrong answers, stated in the same tone as correct ones.
  • Fabricated or mismatched citations — invented sources, and real links that don’t support the claim attached to them. Module 3, Lesson 1 (M3L1) examines this closely.
  • Inconsistency — the same prompt twice, two materially different answers.
  • Staleness on recent events, and answers that blend freshly retrieved material with older material without flagging which is which.
  • Usage limits interrupting work mid-task on the free plan — a practical failure mode, not a quality one, and the one students actually report.
  • Over-hedging — long, qualified answers where a direct one was asked for. The mirror image of ChatGPT’s tendency to agree with you, and worth noticing as a style difference rather than a correctness one.

One phrasing note that matters for the rest of the course: where retrieved web content is involved, it’s a product behaviour, never a model behaviour — “the app searched and gave the model the results,” not “the model searched the web.” M3L1 owns that distinction.
