1. What This Tool Is

What Copilot is, and the two jobs it does in this course.

Microsoft Copilot is Microsoft’s conversational AI assistant. For CSC 141 it fills two specific roles:

  1. The second college-provided tool. Along with Gemini and NotebookLM, it’s available to every student at no cost through the college — no personal account, no credit card, no vendor terms of your own to agree to.
  2. The fallback if Gemini won’t let you in. Every activity in this course can be completed in Copilot. If you’re locked out of Gemini in week 1, come here, get working, and sort out the Gemini problem in parallel.

Gemini remains the course baseline — walkthroughs and screenshots in lessons match Gemini’s screen. Copilot is a fully supported alternative, not a downgrade.

2. Getting Access

Signing in with your college address, and what to do if it doesn’t work.

Three facts to get exactly right before you start:

  • Your student email domain is @student.mendocino.edu. Not @mendocino.edu — that’s staff and faculty.
  • You get the free Microsoft 365 student tier by signing in with that address.
  • Web only. There is no Microsoft 365 desktop/app connection on this tier.

Pending confirmation: college Copilot access was last confirmed with college IT on 2026-07-14; reconfirmation is pending before Fall 2026.

Step by step: signing in to Copilot

  1. Go to Copilot on the web. Open copilot.microsoft.com in a browser tab.

  2. Sign in with your college address. Use your full @student.mendocino.edu address and your college password — the same credentials as your student email.

  3. Check for the shield. Look along the top of the interface, next to the New Chat control, for the green shield icon. That icon is Microsoft’s own indicator that enterprise data protection is switched on for your session — which is what Section 6 is about. If you don’t see it, you’re probably signed in on a personal Microsoft account rather than your college one.

  4. Confirm the account. Open the account menu and verify it shows your @student.mendocino.edu address. Same failure as in Gemini: a personal account still works, but you get consumer terms instead of the college’s, and your coursework lands in a personal account.

  5. Test it. Type Say hello and press Enter. If you get a response, you’re set.

Caution

If Copilot won’t load or asks you to pay:

  • Re-check steps 3 and 4 — wrong-account is the most common cause, same as with Gemini.
  • Sign out of any personal Microsoft account in that browser first, or use a private/incognito window, then sign in fresh with the college address.
  • Still stuck? Contact the college IT help desk and say you need Microsoft Copilot access for CSC 141.
  • While you’re waiting, use Gemini — it’s also college-provided and it’s the course baseline. If both are blocked, tell your instructor; this is an access problem the course has to solve for you, not something you should be fixing with a personal account at an outside company.

3. The Interface

What to look for on screen — described so it still helps you after Microsoft moves things.

Microsoft reorganizes this interface often, so this tour describes what to look for rather than exactly where on the screen it sits. If something has moved, look for the same thing somewhere else on the page before assuming it’s gone.

Interface tour — six things worth finding

The prompt input box

The single text field where you type what you want. Everything you do with Copilot starts here.

The green shield indicator, and where it sits

Along the top of the interface, next to the New Chat control. It is Microsoft’s own signal that enterprise data protection is applied to your session. Its presence or absence is a fact about your account, not about the question you asked.

The conversation thread

Your prompts and Copilot’s responses in sequence. Everything above the current message is context the tool can still refer to.

Starting a new chat vs. continuing one

The New Chat control opens an empty thread with no memory of the previous one. Continuing in the current thread keeps the context.

Chat history

Previous conversations, reachable again later. Worth knowing about before you assume a thread is gone.

Attaching a file or image

An attach control near the input box lets you add a document or image and then ask questions about it.

4. Core Workflow

Three short activities that exercise the interface. The same three appear in every tool guide, in the same order.

These prompts exist to make the buttons do something so you can see what happens. Writing good prompts is a separate skill, taught in Module 2, Lessons 3 and 4 (M2L3–M2L4).

Activity 1 — Ask and follow up

5 min

Task: ask one question, then ask a second question that only makes sense if the first one is remembered.

  1. Open a new chat and paste the first prompt.
  2. Read the response.
  3. In the same thread, paste the follow-up. Don’t repeat the topic — the point is to see whether the thread carries it.

First prompt:

Explain what a community college transfer agreement is, in about four sentences.

Follow-up, in the same thread:

Now say that again for someone who has never heard the word "articulation."

Activity 2 — Attach something

5 min

Task: upload a document or image and ask a question about it.

  1. Find a file you already have — a syllabus, a handout, a photo of a printed page. Nothing personal: no student ID, no grades, nobody else’s work.
  2. Use the attach control near the input box to add it.
  3. Paste the prompt below and send it.

Prompt:

Summarize this document in five bullet points, then list anything in it you are unsure about.

Activity 3 — Start clean

2 min

Task: notice the difference between continuing a thread and starting a new one.

  1. Still in the thread from Activity 2, paste the prompt below. The answer will probably still be coloured by the document you attached.
  2. Now click New Chat and paste the same prompt into the empty thread.
  3. Compare. A long thread carries everything in it — useful when that’s what you want, and a source of drift when it isn’t. When you change topic, start clean.

Prompt (run it twice — old thread, then new chat):

What are three good ways to take notes during a lecture?

5. Free-Tier Limits

What the college tier is — and what this guide can’t yet tell you.

This section is accurate as of August 2026, and it is the fastest-staling section in the guide. Check it against your own screen before relying on it.

The college tier provides standard generative AI access, not the paid products. It is not Copilot Pro, and it is not the licensed Microsoft 365 Copilot that runs inside Word, Excel, Outlook and Teams.

Note

Don’t expect Copilot to appear inside your desktop Office apps. That is a different, licensed product with a similar name. What you have is web access at copilot.microsoft.com, signed in with your college address.

Message caps, upload limits, and image generation

This guide does not publish numbers for these yet. Any message or usage caps, file upload size and type limits, image-generation limits, and what resets and how often — all of it needs to be confirmed against Microsoft’s own documentation and a live college login before it appears here.

Third-party “2026 Copilot limits” pages state confident numbers that contradict each other and cite nothing, and Microsoft’s student and consumer offers are frequently confused with each other — there are separate promotional offers for Microsoft 365 Personal, GitHub Copilot for students, and Copilot Pro trials, and none of those are what this course means. An unsourced figure is exactly the habit this course exists to break, so this section says what is unknown rather than publishing a plausible number.

6. Privacy & Data Handling

What Microsoft does with what you type, what the college can see, and how to check both yourself.

Data posture at a glance

Account
College-provided M365 student tier (@student.mendocino.edu, web only). Pending confirmation: access last confirmed with college IT 2026-07-14; reconfirmation pending before Fall 2026.
Training on your inputs
No. Not used to train Microsoft’s foundation models on a work or school account. Microsoft Learn, verified 2026-08-19
Who else can see it
The college. Prompts and responses are logged in the college’s Microsoft 365 tenant, reachable via administrator audit logging and eDiscovery. Microsoft Learn, verified 2026-08-19
Retention
The college’s own Microsoft 365 retention policy. Microsoft Learn, verified 2026-08-19

The detail

  • Prompts and responses are not used to train Microsoft’s foundation models when you’re signed in with a work or school account. Microsoft’s own wording: “Prompts and responses aren’t used to train the underlying foundation models.” (Microsoft Learn, Microsoft 365 Copilot Chat Privacy and Protections — verified 2026-08-19.)
  • The green shield is the indicator. Microsoft: Copilot Chat “makes it clear that enterprise data protection is applied by featuring a green shield along the top of the user interface next to the New Chat button.” No shield means you’re not covered — check it, don’t assume it.
  • But your prompts and responses are logged and stored inside the college’s Microsoft 365 tenant (in Exchange), under the college’s retention policies, and are reachable through administrator audit logging and eDiscovery. Not-used-for-training and not-visible-to-anyone are two different things.
Verify

The in-product check. Don’t take this guide’s word for the shield. Look for it on your own screen, and check it again if you ever sign in from a different browser or device. Copilot is unusual in showing you its protection status directly; most tools make you go and read a settings page.

Caution

The standing rule, whatever tool you’re using: never enter your student ID, grades, other students’ work, or anyone’s personal information.

7. Known Weaknesses

The failure modes you will actually hit in this course.

  • Confident wrong answers, stated in the same tone as correct ones.
  • Citations that don’t hold up. When Copilot returns links, some will be real pages that don’t actually support the sentence they’re attached to. Module 3, Lesson 1 (M3L1) examines this failure mode closely.
  • Inconsistency — the same prompt run twice can produce materially different answers.
  • Refusals and truncation on topics the enterprise filtering treats as sensitive, sometimes on legitimate coursework.
  • Staleness on recent events, and answers that mix current retrieved material with older material without flagging which is which.

One phrasing note that matters for the rest of the course: when recent web content shows up in an answer, the app searched and gave the model the results — the model didn’t search the web. M3L1 owns that distinction.
